Hearth Room은 PrivateClaw의 iPhone / iPad 클라이언트입니다. PrivateClaw는 직접 호스팅하는 AI 어시스턴트를 위해 신뢰하는 사람들만 모이는 초대 전용 암호화 채팅방을 만들어 주는 오픈소스 채팅 시스템입니다.

작동 방식:
- PrivateClaw 데스크톱 구성 요소(무료, Windows / macOS / Linux)는 사용자의 컴퓨터에서 선택한 AI 어시스턴트와 함께 실행되며, 채팅방을 만들고 일회용 QR 초대를 발급합니다.
- Hearth Room은 휴대폰에서 채팅방에 참여합니다. 초대를 스캔하거나(또는 초대 링크를 붙여넣어) 친구들 및 어시스턴트와 채팅하세요. 사진, 음성 메모, 파일도 같은 암호화 채팅방 안에서 전송됩니다.
- 릴레이는 암호문만 전달하며 메시지 내용을 절대 볼 수 없습니다. 계정 가입도 필요 없습니다.

기능:
- 스캔 한 번 또는 링크 붙여넣기로 참여
- 릴레이 경유 종단 간 암호화
- 신뢰하는 사람만 초대하는 그룹 채팅방
- 자체 호스팅 / 클라우드 사용자 지정 릴레이 지원
- 슬래시 명령, 미디어, 참여자 상태 표시

Hearth Room은 연결할 PrivateClaw 채팅방이 필요합니다. 데스크톱 구성 요소는 무료 오픈소스입니다: https://github.com/topcheer/PrivateClaw (Windows 앱은 Microsoft Store에 있습니다).

푸시 알림은 공식 릴레이 relay.privateclaw.us에서만 기본으로 사용할 수 있습니다. 사용자 지정 릴레이를 사용하는 경우 릴레이와 앱 빌드를 자체 Firebase / FCM 프로젝트에 연결하세요.
