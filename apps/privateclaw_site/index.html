Install the OpenClaw plugin

Install from ClawHub. Pair. Done.

PrivateClaw is a ClawHub-reviewed plugin, so the official registry install works on current OpenClaw hosts with no override flags. Install, enable, restart the gateway, and pair from the CLI or from any chat channel.

Recommended

Install the plugin from ClawHub

This is the official path. ClawHub serves the audited package, OpenClaw verifies it, and the plugin is enabled in two commands.

openclaw plugins install clawhub:@privateclaw/privateclaw --accept-capabilities
openclaw plugins enable privateclaw

On current OpenClaw hosts the bare form `openclaw plugins install @privateclaw/privateclaw` resolves to ClawHub as well. Restart the OpenClaw gateway after enabling so it loads the plugin.

Then

Restart the gateway and pair

Restart OpenClaw, then open a pairing link from the CLI or create a room invite from any existing OpenClaw chat channel.

openclaw privateclaw pair --open
/privateclaw
/privateclaw group

Use `openclaw privateclaw pair --group --open` or `/privateclaw group` when you want multiple people sharing the same room.

Alternative

One-command setup wizard

If you would rather not run the plugin commands by hand, the npx wizard installs or updates the plugin, enables it, restarts the gateway, and walks you straight into pairing.

npx -y @privateclaw/privateclaw@latest

The wizard asks for single or group chat and a session duration from 30 minutes to permanent. It pulls the npm package directly, so it is also the fastest way to pick up a brand-new patch.

FAQ

Questions people ask

Short answers about what Hearth Room and PrivateClaw are, how they work and what they cost.

What is Hearth Room?

Hearth Room is the PrivateClaw client: an app for iPhone, iPad, Mac, Windows, Linux and the web that joins end-to-end encrypted chat rooms created by PrivateClaw on your computer.

Is it free?

Yes. PrivateClaw, the OpenClaw plugin and Hearth Room are open source and free to use, with no account, subscription or in-app purchase.

How private is it?

Messages, photos, voice notes and files are end-to-end encrypted between the members of a room. The relay only routes ciphertext and never sees the content or the keys.

How do rooms and invites work?

A room is created with a one-time QR code or invite link and can be set to expire after a few hours, days or a longer period. Anyone with the invite can join until it expires or is revoked.

Which platforms are supported?

Hearth Room runs on iOS and iPadOS, macOS, Windows and Linux, plus a web chat in the browser. An Android version is in closed testing.

How does it relate to OpenClaw?

PrivateClaw is a plugin for OpenClaw, the assistant runtime you run on your own computer. It creates the rooms, issues the invites and lets your OpenClaw assistant answer inside them.
